# Implantación, soporte y servicios

El código propio puede utilizarse, modificarse y redistribuirse bajo Apache 2.0 sin contratar servicios de TECH friendly. La licencia del código y la contratación de servicios son acuerdos distintos.

## Servicios que pueden acordarse

- Implantación y configuración en la infraestructura de una organización.
- Integración con identidad, almacenamiento, modelos y sistemas corporativos.
- Migración de datos y preparación de fuentes autorizadas.
- Formación, acompañamiento y adaptación de recorridos.
- Mantenimiento, soporte y condiciones de operación.

La prestación por TECH friendly de cualquiera de estos servicios requiere un contrato específico que determine alcance, entregables, precio, responsabilidades y, cuando corresponda, niveles de servicio. Este repositorio no concede soporte garantizado ni fija tarifas o compromisos de disponibilidad.

## Entrega del software

Una entrega puede incluir el código y documentación bajo Apache 2.0 junto con servicios contratados. El contrato no debe presentarse como una condición para ejercer derechos que la licencia abierta ya concede. Las dependencias conservan sus condiciones: consulta [LICENSING.md](LICENSING.md) y [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Las condiciones concretas de titularidad, protección de datos, garantías y distribución de componentes deben revisarse en el contrato de cada prestación. No se concede exclusividad sobre el código abierto por contratar soporte.

Para localizar un canal de contacto de la organización, visita el [perfil de TECH friendly](https://github.com/techfriendly). Para ayuda comunitaria, consulta [SUPPORT.md](SUPPORT.md).
