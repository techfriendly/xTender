# Tu primer recorrido con xTender

1. **Crea un expediente.** Identifica la necesidad, unidad responsable, objeto y datos básicos. El entorno inicial no contiene expedientes reales ni demostraciones precargadas.
2. **Prepara el contexto.** Completa planificación, riesgos y magnitudes económicas. Incorpora fuentes y plantillas propias cuando dispongas de ellas.
3. **Elige el documento.** Informe de necesidad, PPT y PCAP tienen índices y preguntas propios. El informe jurídico es un documento complementario separado.
4. **Revisa el índice.** Ajusta capítulos y valida la estructura antes de pedir redacción asistida.
5. **Redacta y contrasta.** Selecciona referencias, genera propuestas por capítulo y revisa sus citas. Puedes editar manualmente; la regeneración se presenta como propuesta comparable.
6. **Comprueba la coherencia.** Examina incidencias y cambios de datos compartidos. Acepta o rechaza las propagaciones de forma explícita.
7. **Valida la versión.** Un texto generado necesita aceptación humana antes de declararse final.
8. **Exporta.** Descarga documentos DOCX o el paquete del expediente con los datos y trazas disponibles.

Un fallo del proveedor de IA debe revisarse como tal. Contrasta referencias y afirmaciones jurídicas antes de utilizar un documento. La aplicación asiste al equipo responsable y conserva su intervención.
