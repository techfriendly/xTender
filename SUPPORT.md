# Ayuda y comunidad

- **Instalación y uso:** empieza por el [README](README.md) y la documentación enlazada.
- **Errores reproducibles:** abre una [issue](https://github.com/techfriendly/xTender/issues/new/choose) con versión, entorno y pasos usando datos ficticios.
- **Ideas y mejoras:** explica el problema del usuario y el resultado esperado en una propuesta de funcionalidad.
- **Vulnerabilidades:** usa el canal privado de [SECURITY.md](SECURITY.md).

El soporte comunitario se presta según disponibilidad. Este repositorio no incluye un acuerdo de nivel de servicio. Para conocer al equipo impulsor, visita [TECH friendly](https://github.com/techfriendly).
